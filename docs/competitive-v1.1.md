## 一、产品一句话

> **把"我记得某段话的某个细节"变成"找到那一句，并指给你看"**——跨会话全文检索，命中到会话内的具体片段（高亮 + 前后文），一键定位到旧会话里的那条消息。

## 二、v1.1 功能清单（已实现）

| 能力 | 说明 |
|---|---|
| 跨会话全文搜索 | 官方 SQLite FTS5（searchSessions），跨工作区、工作区/日期过滤、分页 |
| **片段级命中** | 每会话返回**最佳命中片段**（事件级 seq + snippet，高亮） |
| **前后文窗口** | 命中片段前后文（readEvent 窗口，灰字） |
| **定位到具体消息** | 打开旧会话 + 分页前翻 + DOM 滚动到命中消息行（2s 高亮反馈） |
| @召回（兜底） | 一键把会话以 @引用 插入输入框，发送后注入快照 |
| 归档支持 | 搜索含归档、带徽标、可筛选 |

## 三、竞品比对（插件库实测）

| 能力维度 | 竞品 | 与 v1.1 的关系 |
|---|---|---|
| **跨会话全文搜索** | 内置侧边栏搜索（会话级 snippet）；dsh-session-search-pro；dsh-plugin-kit#search | 🟡 我们**更细一层**：片段 + 前后文 + 定位 |
| **会话内定位/跳转** | 🔴 饱和（10+ 个）：dsh-indexbookmark、dsh-chat-timeline（官方移植 20★）、dsh-codex-timeline、dsh-milestone、dsh-strata、dsh-turn-rail、dsh-navbar、dsh-history、dsh-turn-marks、dsh-conversation-density-map | **全部是"本会话内"导航**——不解决"跨会话找旧片段" |
| 前后文/摘要/预览 | dsh-session-flow、dsh-session-viz、dsh-replay、dsh-archived-conversations | 🟡 有摘要/预览，但**不是"检索命中→片段→定位"工作流** |
| **跨会话检索 → 片段 → 定位 → 召回 闭环** | **无竞品** | 🟢 **生态唯一** |

## 四、差异化结论（发布核心主张）

**生态里没有第二个插件做到「跨会话检索 → 片段级命中 → 定位到旧会话具体消息」的完整闭环。**

- 竞品分两拨，各缺一半：
  - **跨会话搜索类**（内置/插件）：搜得到会话，但停在一个 snippet，没有前后文展开、没有定位、没有召回闭环；
  - **会话内导航类**（10+ 个）：能跳转，但**只在本会话内**——解决不了"旧会话里那句话在哪"。
- **v1.1 是唯一把两半接起来的**：跨会话搜 → 片段命中 → 打开旧会话定位到那一句 → 可再 @召回。

## 五、用户价值（发布话术）

| 场景 | 价值 |
|---|---|
| "我之前说过 X，在哪说的？" | 搜关键词 → 直接命中那一句（不是整个会话）→ 定位跳转 |
| "那个会话里 AI 大概怎么答的？" | 片段 + 前后文，不用打开整会话翻 |
| "把当时那段上下文带回来" | 定位确认后，@召回 整会话给 AI（平台兜底） |

## 六、边界（诚实声明，避免过度承诺）

1. **平台限制**：`@引用` 仅支持会话级——片段定位是"给人看"，不能把单句片段喂给 AI；
2. **定位为 best-effort**：命中句过短/常见文本可能定位到相邻消息；超长会话（>500 条窗口）的老片段可能无法自动定位（有降级提示）；
3. **每会话返回一个最佳片段**（同会话多命中留 v1.2）。

## 七、发布建议引用

- **GitHub description 关键词**：`session search` `snippet-level` `locate` `recall` `cross-session` `片段级检索` `定位`;
- **展示帖要点**：差异化 = "跨会话检索 + 片段级命中 + 定位到旧会话具体消息"（生态唯一闭环），配 2~3 张截图（片段卡片 / 定位高亮 / 前后文）；
- **不建议声称**："语义检索""片段级召回给 AI"（平台不支持，会被竞品评审/用户质疑）。
